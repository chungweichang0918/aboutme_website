## Sensor node

A team entry for the HOLTEK MCU contest. The firmware reads several sensors and sends measurements to the upper-level system through a Wi-Fi module.

## Dashboard

The interface presents sensor values with status cards and trend charts, and marks soil as dry, wet, or balanced according to the thresholds of the selected mode. Readings and trends can be checked side by side on site.
